# GameHub

GameHub is an interactive online game store built with JavaScript that consumes a public API to dynamically display products and manage a shopping cart. The project focuses on asynchronous JavaScript, API integration, and client-side application logic.

## Features

- Dynamic product list fetched from a public API
- Product filtering by category and genre
- Individual product detail pages
- Shopping cart with add and remove functionality
- Checkout flow with order confirmation

## Prerequisites

No special setup required.  
A modern web browser is sufficient to run the project.

## Getting Started

### Installation

```bash
npm install
```

### Running the project

```bash
npm run dev
```

## Available Scripts

- `npm run dev` - Start development server
